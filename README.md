
# Memory Allocation Simulation

## 1. Project Description

This project simulates memory allocation in a computer system with a fixed memory capacity of 100 MB.

It compares three memory allocation algorithms:
- First Fit
- Best Fit
- Worst Fit

The simulation also investigates the effect of minimum split thresholds on memory fragmentation and allocation performance.

## 2. Experimental Configuration

- Total memory capacity: 100 MB
- Allocation algorithms: First Fit, Best Fit, Worst Fit
- Minimum split thresholds: 0 MB, 2 MB, 5 MB, 10 MB

Three allocation-only workloads were tested:
- Small workload
- Large workload
- Mixed workload

Two additional dynamic scenarios included memory allocation and deallocation operations.

## 3. Number of Experiments

The simulation contains 60 experimental runs:
- 36 allocation-only experiments
- 12 Dynamic Scenario 1 experiments
- 12 Dynamic Scenario 2 experiments

## 4. Evaluation Metrics

The simulation evaluates performance using:
- External fragmentation
- Internal fragmentation
- Allocation success and failure
- Memory utilization

## 5. Project Structure

- `main.py` – Python implementation of the simulation.
- `results/experimental_results.txt` – Experimental output generated by the program.
- `README.md` – Project description and instructions.
- `requirements.txt` – External Python dependencies, if required.

## 6. How to Run

1. Open the project in IntelliJ IDEA or another Python environment.
2. Make sure Python 3 is installed.
3. Open `main.py`.
4. Run the Python file.
5. The program displays the experimental results in the console.

## 7. Reproducibility

The experiments use predefined workloads, allocation algorithms, threshold values, and dynamic scenarios.

All experiments use the same memory capacity of 100 MB to allow comparison under controlled conditions.

The complete experimental output is available in:
`results/experimental_results.txt`
